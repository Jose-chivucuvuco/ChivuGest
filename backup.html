Backup e Recuperação

Área exclusiva do Administrador para proteger e recuperar os dados do ChivuGest.

Importante: o backup descarregado deve ser guardado fora do servidor/Render. Esta função cria uma cópia dos dados da aplicação; os documentos físicos/PDF armazenados externamente devem ter a sua própria política de cópia.

Criar backup

Inclui fornecedores, faturas, pagamentos, conta corrente, contratos, contratação pública, utilizadores, regras legais e alertas.

Restaurar backup

A restauração substitui os dados atuais pelos dados do ficheiro selecionado. Faça um backup atual antes de restaurar.
