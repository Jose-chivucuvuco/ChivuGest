CHIVUGEST ONLINE
Versão web multiutilizador com PostgreSQL, login, utilizadores, dashboard, clientes, faturas, pagamentos, conta corrente, importação CSV/XLSX e PDF/OCR.

Para teste local:
python -m pip install -r requirements.txt
python app.py
Abra http://127.0.0.1:5000

Para produção, use PostgreSQL e Gunicorn. Consulte DEPLOY.md.
